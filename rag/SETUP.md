# Football RAG System — Setup Guide

## Architecture

```
rag/
├── __init__.py                  ← Public API
├── extract_tactics.py           ← Step 1: Extract attack/defense from JSONL
├── build_neo4j_kg.py            ← Step 2a: Populate Neo4j
├── build_postgres_db.py         ← Step 2b: Populate PostgreSQL
├── build_faiss_index.py         ← Step 3: Build FAISS vector index
├── rag_orchestrator.py          ← Step 4: Main RAG system
├── knowledge_base/
│   └── team_tactics.json        ← Auto-generated by extract_tactics.py
├── vector_store/
│   ├── faiss.index              ← Auto-generated by build_faiss_index.py
│   └── faiss_metadata.json      ← Auto-generated by build_faiss_index.py
└── providers/
    ├── __init__.py
    ├── base.py                  ← Abstract base classes
    ├── kg_provider.py           ← Neo4jProvider + PostgreSQLProvider
    └── vector_provider.py       ← FAISSProvider
```

## One-time Setup

### 1. Prerequisites

```bash
# Start Neo4j (choose one):
# Option A — Neo4j Desktop: download from https://neo4j.com/download/
# Option B — Docker:
docker run -p 7474:7474 -p 7687:7687 -e NEO4J_AUTH=neo4j/password neo4j:latest

# Start PostgreSQL (choose one):
# Option A — Already installed: make sure it's running
# Option B — Docker:
docker run -p 5432:5432 -e POSTGRES_PASSWORD=password postgres:15
```

### 2. Configure `models/llm_config.yaml`

Update these fields with your actual credentials:

```yaml
rag:
  neo4j_password: "your_neo4j_password"
  postgres_dsn:   "postgresql://postgres:your_password@localhost:5432/football_rag"
```

### 3. Create the PostgreSQL database

```sql
-- In psql or pgAdmin:
CREATE DATABASE football_rag;
```

### 4. Run the build pipeline

```bash
# From the project root:

# Step 1 — Extract tactics from your LLM analyses
python rag/extract_tactics.py

# Step 2a — Build Neo4j Knowledge Graph
python rag/build_neo4j_kg.py

# Step 2b — Build PostgreSQL database
python rag/build_postgres_db.py

# Step 3 — Build FAISS vector index
python rag/build_faiss_index.py
```

## Using the RAG System

### Python API

```python
from rag import FootballRAGSystem

# Default (Neo4j + FAISS + HuggingFace Qwen3-0.6B fine-tuned)
rag = FootballRAGSystem()

# Switch providers (no other code changes needed)
rag_gemini   = FootballRAGSystem(llm="gemini")
rag_postgres = FootballRAGSystem(kg="postgres", llm="ollama")

# Available query methods
answer = rag.query("How has Arsenal been performing recently?")
answer = rag.predict_match("Arsenal", "Chelsea")
answer = rag.get_team_report("Liverpool")
answer = rag.compare_teams("Barcelona", "Real Madrid")
```

### CLI

```bash
# Interactive chat
python rag/rag_orchestrator.py

# Match prediction
python rag/rag_orchestrator.py --predict Arsenal Chelsea

# Team report
python rag/rag_orchestrator.py --team Liverpool

# Custom query
python rag/rag_orchestrator.py --query "How does Bayern Munich defend?"

# Switch provider
python rag/rag_orchestrator.py --llm gemini --predict Barcelona "Real Madrid"
python rag/rag_orchestrator.py --kg postgres --predict Arsenal Chelsea
```

## Provider Switching

To change any provider, edit `models/llm_config.yaml`:

```yaml
rag:
  kg_provider:     neo4j       # → postgres (switch to PostgreSQL)
  vector_provider: faiss       # (only FAISS for now)
  llm_provider:    huggingface # → gemini | ollama | openai
```

Or pass at runtime:

```python
rag = FootballRAGSystem(kg="postgres", llm="gemini")
```

## What's in the Knowledge Graph

### Team Nodes (Neo4j) / `teams` table (PostgreSQL)
| Field | Description |
|-------|-------------|
| `name` | Team name |
| `league` | Primary league |
| `total_matches` | Total matches in dataset |
| `avg_goals_home` | Avg goals scored at home |
| `avg_goals_away` | Avg goals scored away |
| `avg_xg` | Avg Expected Goals |
| `avg_xga` | Avg Expected Goals Against |
| `seasons` | Seasons present in dataset |
| `attack_tactic` | Extracted attack style description |
| `defense_tactic` | Extracted defense style description |

### Match Edges (Neo4j) / `matches` table (PostgreSQL)
Shots, corners, fouls, cards, xG, goals, result, form, H2H, referee — all 40+ features.

## Verification

After building, verify:

```python
from rag.providers.kg_provider import get_kg_provider
from rag.providers.vector_provider import get_vector_provider

kg = get_kg_provider("neo4j")
print(kg.get_team_profile("Arsenal"))       # Should show stats + tactics
print(kg.get_head_to_head("Arsenal", "Chelsea", limit=3))

vec = get_vector_provider("faiss")
print(vec.get_index_size())                 # Should show 7,083+ vectors
results = vec.search("Arsenal attacking press", k=3)
for r in results:
    print(r["metadata"]["home_team"], "vs", r["metadata"]["away_team"])
```
